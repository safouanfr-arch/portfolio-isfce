# ISFCE Software Portfolio

Course and graduation projects by Safouan Tassi, with reproducible labs and selected design artifacts.

| Project | Focus |
| --- | --- |
| [Terra Sana](https://github.com/safouanfr-arch/terra-sana) | Spring Boot and Vue 3 platform for local ordering, stock and pickup |
| [Presse Ocean](https://github.com/safouanfr-arch/Projet-Web) | Vue and PHP news application with search and session favorites |
| [Academic exemptions](exemptions/) | Dossier workflow, data model and prototype screenshots |
| [SQL and Firebird](sql/) | Relational constraints, joins, stored procedures and triggers |
| [Statistics in R](statistics/) | Descriptive statistics, simulation, regression and inference |
| [Networking](networking/) | IPv4 subnet calculations and a Packet Tracer practice topology |
| [Modelling and planning](modelling/) | Relational modelling and project dependencies |
| [Other course exercises](coursework/) | Python selection exercise and related coursework |

The e-commerce [front-end prototype](https://github.com/safouanfr-arch/DEMO-E-COMMERCE) and [SQL design](https://github.com/safouanfr-arch/SQL-DB-Site-E-commerce) document earlier iterations of Terra Sana. The [ULB programming portfolio](https://github.com/safouanfr-arch/portfolio-ulb) covers C, Python and Bash projects from a separate course program.

Public lab datasets and scenarios are classroom samples or synthetic. See each section for the origin and how to run it.
